# Stage 5 demo

The marketplace is at `/marketplace`, collaboration at `/collaboration`, and both new geographic layers appear on `/map`. Sign in with a verified account. A farm organization needs admin verification and an approved public pickup location before offering crops; recipient organizations need verification before requesting produce or publishing a recipient profile. The organization list on the marketplace page shows verification state, and admins can review the pending queue there.

Run the Stage 5 migration with `pnpm --filter @cropcircle/api db:migrate:deploy`. The S3 compatible demo service in `compose.yaml` is SeaweedFS on port 8333; configure `S3_ENDPOINT`, `S3_PUBLIC_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY`, and `S3_SECRET_KEY` as shown in `apps/api/.env.example`. `S3_AUTO_CREATE_BUCKET=true` is for local demo setup. Uploaded images and PDF attachments use short lived signed URLs. Group files require membership to read.

Marketplace API: `/marketplace/listings`, `/marketplace/recipients`, `/marketplace/requests`, `/marketplace/map`, and `/marketplace/recipients/map`. Listing and profile writes require verified organization membership; listing writes require a farmer or farm organization. Requests have pending, accepted, rejected, cancelled, and fulfilled states. Acceptance reserves partial quantities using a conditional PostgreSQL update inside a transaction. Search hides expired, removed, and fully reserved offers. Sale listings record price and a purchase request, but payment and settlement happen outside this demo.

Collaboration API: `/collaboration/issues`, `/collaboration/issues/:id/similar`, `/collaboration/experts`, `/collaboration/groups`, `/collaboration/invitations`, and group post/observation endpoints. Issue reports are explicitly unverified and expose a general region instead of private coordinates. Similarity uses crop, category, interests, and optional geographic proximity. Group discussions and attachments require membership.

Validation: `pnpm --filter @cropcircle/api typecheck`, `test`, `build`; `pnpm --filter @cropcircle/web typecheck`, `lint`, `build`; and `pnpm --filter @cropcircle/api exec tsx test/stage5.integration.ts` against local PostgreSQL/PostGIS and S3 compatible storage. The integration fixture tests concurrent acceptances, fulfillment, cancellation, geographic discovery, group membership, and media access, then removes its data.
