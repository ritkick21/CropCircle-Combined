# Stage 4 resource map

`ResourceLocation` is the public map projection. It deliberately does not read `Site.exactGeog`, which remains the private pickup coordinate. A member with owner or manager scope creates an unpublished resource; an admin publishes it after verifying that the location is suitable for public display and entering a review reason. The reviewer and reason are retained in `resource_location_reviews`. Farms and foster-support resources are stored at roughly 0.1-degree precision and have no public address label; a database check enforces both rules. Suspended or deleted organizations are omitted from all discovery queries.

The authenticated endpoints are `GET /api/v1/locations`, `/locations/nearby`, `/locations/:id`, `/locations/mine`, `/map/markers`, and `/map/filters`. `POST /locations/organizations/:organizationId` creates a pending resource; `PATCH /locations/:id` lets its organization manager update it. A change to its public name, address, or point removes it from discovery until reviewed again. Admin-only `GET /locations/pending` and `POST /locations/:id/publish` support review. List queries accept `q`, `category`, `crop`, `available`, `lat`, `lng`, `radiusKm`, `limit`, and `offset`. Nearby requires coordinates and a radius. Markers require a bounding box and support limit/offset pagination. The web app reads up to 2,000 visible points, shows the total when truncated, and asks the user to zoom in; MapLibre clusters the loaded points in the browser. The PostGIS GiST index supports bounding-box and `ST_DWithin` filters. Distances use `ST_Distance` in meters.

The browser uses MapLibre GL JS and the [OpenFreeMap Liberty style](https://openfreemap.org/quick_start/) by default. `NEXT_PUBLIC_MAP_STYLE_URL`, `NEXT_PUBLIC_GEOCODE_URL`, `NEXT_PUBLIC_ROUTE_URL`, and `NEXT_PUBLIC_API_URL` are passed as Docker build arguments because Next.js embeds them in its client bundle. The map signs in through the existing auth API, keeps its short-lived access token in memory, and refreshes through the HttpOnly cookie. [Photon](https://github.com/komoot/photon/blob/master/docs/api-v1.md) powers place search and [OSRM](https://github.com/Project-OSRM/osrm-backend/blob/master/docs/http.md) powers driving routes. Their public demo endpoints are suitable for development only; configure self-hosted or contracted instances for a production deployment. Routing is disabled for farmer and foster-support markers because their point is intentionally coarse.

The checked-in Prisma migrations were applied to the local PostgreSQL/PostGIS database. The transactional integration test exercises create, publish with a review record, nearby and bounding-box search including the date line, manager update, draft visibility, and coarse-coordinate protection. The transaction rolls back its fixtures. Browser verification on desktop and mobile confirmed tiles, a database marker, detail panel, category toggle, nearby distance, place search, and driving-route line. The temporary browser fixture was removed afterward.
